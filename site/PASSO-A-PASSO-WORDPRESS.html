Publicar o site Coli Loterias no WordPress

Passo a passo completo para colocar o site 100% funcional em coliloterias.com.br, com resultados e estatísticas se atualizando sozinhos.

⏱ Tempo estimado: 20 a 30 minutos. Você vai precisar do login do painel da hospedagem (cPanel, Plesk, Hostinger, Locaweb, HostGator, KingHost…) ou de um acesso FTP, e do login do WordPress.

Como o site funciona (resumo)

O site é um conjunto de páginas HTML + um pequeno arquivo PHP. Ele não usa banco de dados e não depende de tema ou plugin do WordPress. Fica em uma pasta própria dentro da hospedagem, ao lado do WordPress, e o WordPress só precisa de um link no menu apontando para ele.

public_html/                ← pasta pública da hospedagem
├── wp-admin/               ← WordPress (não mexa)
├── wp-content/             ← WordPress (não mexa)
├── wp-config.php, index.php …
└── loterias/               ← ★ o site novo (conteúdo do zip)
    ├── index.html, resultados.html, estatisticas-*.html
    ├── api/loterias.php    ← consulta a API oficial da CAIXA
    ├── api/cache/          ← cache (precisa de permissão de escrita)
    ├── data/               ← histórico de todos os concursos (escrita)
    └── assets/             ← css, js, imagens

Quando alguém abre o site, o navegador chama api/loterias.php, que consulta a CAIXA, guarda em cache por 10 minutos e devolve os resultados. Quando sai um sorteio novo, o PHP baixa só o concurso novo, acrescenta ao histórico em data/ e todas as estatísticas já saem recalculadas.

Parte 1 — Preparar o zip

1 Confira os dados da lotérica

Extraia o zip no seu computador e abra o arquivo coli-loterias/assets/js/coli-config.js no Bloco de Notas (ou em qualquer editor de texto). Ele já vem preenchido com os dados públicos da Coli; confirme e ajuste:

whatsapp:  "551120637676",   ← WhatsApp da loja (55 + DDD + número)
telefones: ["(11) 2063-7676"],
horario:   "Seg a Sex 9h às 18h · Sáb 9h às 12h",
instagram: "https://www.instagram.com/coli_loterias/",
facebook:  "https://www.facebook.com/ColiLoterias/",

Salve o arquivo. Se você editou, compacte a pasta coli-loterias de novo em um zip (botão direito → Enviar para → Pasta compactada) ou envie o arquivo editado separadamente depois do passo 4.

O número do WhatsApp aparece em todos os botões "Fale conosco", "Jogar" e nos jogos gerados pela surpresinha. Teste-o no celular antes de publicar.

2 (Opcional) Troque o logo

Se tiver o logo em melhor resolução, substitua assets/img/logo.png mantendo o mesmo nome. Use PNG com fundo transparente, aproximadamente 360 × 115 px.

2b (Opcional) Avaliações do Google automáticas

  1. Descubra o Place ID da Coli em developers.google.com/maps/documentation/places/web-service/place-id.
  2. Em console.cloud.google.com, crie um projeto, ative a Places API (New) e gere uma chave de API.
  3. Abra api/config.php e preencha GOOGLE_PLACE_ID e GOOGLE_API_KEY.
  4. Depois de publicar, teste …/loterias/api/avaliacoes.php: deve responder "ok":true.
O Google entrega até 5 avaliações por consulta pela API pública. A seção mescla essas com a lista fixa do coli-config.js. Para exibir todas as avaliações do perfil, use um widget (Elfsight/Trustindex).

2c Blog automático

O blog já vem com 14 matérias sobre as Loterias CAIXA, otimizadas para SEO e para respostas de IA (GEO). Elas entram no ar sozinhas, uma a cada 15 dias, a partir da data do pacote. Não há nada a configurar. Para novas matérias, edite tools/blog_posts.py e gere o pacote de novo.

Envie sitemap.xml ao Google Search Console (https://coliloterias.com.br/loterias/sitemap.xml) para acelerar a indexação.

Parte 2 — Subir para a hospedagem

3 Entre no Gerenciador de Arquivos

  1. Faça login no painel da hospedagem (ex.: cpanel.seuprovedor.com.br ou o painel da Hostinger/Locaweb).
  2. Abra o Gerenciador de Arquivos (File Manager).
  3. Entre na pasta pública do site. Normalmente é public_html/. Você sabe que está no lugar certo quando vê as pastas wp-admin e wp-content.
Alternativa por FTP: use o FileZilla com os dados de FTP do painel e envie a pasta coli-loterias inteira (já extraída) para dentro de public_html/.

4 Envie e extraia o zip

  1. Clique em Upload (Carregar) e escolha coli-loterias.zip. Aguarde 100%.
  2. Volte para a lista, clique com o botão direito no zip → Extract (Extrair) → confirme em public_html.
  3. Vai aparecer a pasta coli-loterias. Clique com o botão direito → Rename → renomeie para loterias (nome curto para o endereço ficar coliloterias.com.br/loterias/).
  4. Apague o arquivo zip enviado (não é mais necessário).

5 Dê permissão de escrita em duas pastas

O PHP precisa gravar o cache e o histórico atualizado.

  1. Entre em loterias/api/, botão direito na pasta cache → Permissions (Permissões) → marque 755 → Salvar.
  2. Volte para loterias/, botão direito na pasta data → Permissions → 755 → Salvar. Marque a opção de aplicar aos arquivos dentro dela, se houver.
Se no passo 6 aparecer "cache_gravavel": false ou "data_gravavel": false, repita com 775. Só como último recurso use 777.

6 Teste a conexão com a CAIXA

Abra no navegador:

https://coliloterias.com.br/loterias/api/loterias.php?acao=status

Resposta esperada:

{"ok":true,"php":"8.x","curl":true,"cache_gravavel":true,"data_gravavel":true,"caixa_online":true,...}
Se aparecer…O que fazer
"caixa_online": falseA hospedagem bloqueia conexões de saída ou a CAIXA está fora do ar no momento. Recarregue em 1 minuto. Se persistir, peça ao suporte da hospedagem para liberar conexões HTTPS de saída (cURL) para servicebus2.caixa.gov.br. Enquanto isso o site funciona com as fontes de reserva.
"curl": falsePeça ao suporte para ativar a extensão cURL do PHP (é padrão em qualquer plano).
Erro 403 / página do plugin de segurançaUm plugin (Wordfence, iThemes, All In One Security) bloqueou o PHP fora do WordPress. Adicione /loterias/ à lista de exceções (allowlist) do plugin ou nas regras do .htaccess dele.
Erro 500Versão de PHP muito antiga. No painel, em Selecionar versão do PHP, escolha 8.1 ou superior.
Página em branco ou download do arquivoO PHP não está sendo executado nessa pasta. Confirme que enviou para dentro de public_html (não para uma pasta de arquivos estáticos/CDN).

7 Abra o site

https://coliloterias.com.br/loterias/

Em poucos segundos a faixa verde "Atualizado com a CAIXA às hh:mm" deve aparecer no bloco "Próximos concursos", e os valores de prêmio devem preencher o topo. Clique em uma loteria para ver o último resultado e depois em Estatísticas para conferir o histórico completo.

Parte 3 — Ligar ao WordPress

8 Coloque o link no menu do WordPress

  1. Entre em coliloterias.com.br/wp-admin.
  2. Vá em Aparência → Menus (ou, em temas de bloco, Aparência → Editor → Navegação).
  3. Em Adicionar itens do menu → Links personalizados: URL /loterias/, texto Resultados e Estatísticas. Clique em Adicionar ao menu.
  4. Repita, se quiser, com /loterias/resultados.html (texto "Resultados") e /loterias/estatisticas-megasena.html (texto "Estatísticas").
  5. Salvar menu.

9 Escolha como o site novo aparece em coliloterias.com.br

Três opções, da mais simples para a mais completa. Você pode começar pela A e mudar depois.

Opção A — Site novo em /loterias/ e WordPress continua na home

É o que os passos até aqui já fizeram. Nada mais a fazer.

Opção B — O site novo vira a página inicial de coliloterias.com.br (recomendado)

O WordPress continua instalado (para o wp-admin e o que mais você usa), mas quem abre coliloterias.com.br cai direto no site novo.

  1. No Gerenciador de Arquivos, em public_html/, abra o arquivo .htaccess (ative "Mostrar arquivos ocultos" se não aparecer) → Edit.
  2. Cole estas linhas no topo do arquivo, antes de # BEGIN WordPress:
# Coli Loterias: home aponta para o site novo
RewriteEngine On
RewriteCond %{REQUEST_URI} ^/$
RewriteRule ^$ /loterias/ [R=302,L]
  1. Salve. Abra coliloterias.com.br em uma aba anônima: deve abrir o site novo.
  2. Quando estiver satisfeito, troque 302 por 301 (redirecionamento definitivo, melhor para o Google).
Não tem .htaccess (servidor Nginx, ex.: alguns planos Hostinger/Locaweb)? Instale o plugin gratuito Redirection no WordPress e crie a regra: origem ^/$ (regex) → destino /loterias/.

Opção C — Mostrar o site dentro do layout do WordPress (iframe)

Útil se você quer manter o cabeçalho e o rodapé do tema atual.

  1. Páginas → Adicionar nova, título "Loterias".
  2. Adicione um bloco HTML personalizado e cole:
<iframe src="/loterias/index.html" style="width:100%;min-height:100vh;border:0"
        title="Coli Loterias" loading="lazy"></iframe>
  1. Se o tema tiver a opção, escolha o modelo Largura total / Full width. Publique e coloque a página no menu.
Não cole o HTML das páginas diretamente em um bloco do WordPress: o site tem 12 páginas ligadas entre si, arquivos de dados e o PHP, e isso só funciona com a pasta inteira na hospedagem.

10 Ajustes finais

  • Plugin de cache (WP Rocket, LiteSpeed, W3 Total Cache, Cloudflare): adicione /loterias/api/* às exclusões de cache. Caso contrário o plugin pode "congelar" o resultado por horas.
  • Cloudflare: após publicar, faça Purge Everything em Caching. Crie uma Cache Rule de Bypass para coliloterias.com.br/loterias/api/*.
  • HTTPS: todos os caminhos do site são relativos, então funciona em http e https sem ajuste.
  • Google Analytics / Pixel: se usar, cole o código antes de </head> em cada arquivo .html da pasta (ou peça para incluir no próximo pacote).

Parte 4 — Checklist final

  • loterias.php?acao=status mostra caixa_online: true e as duas pastas graváveis.
  • A página inicial mostra a faixa verde "Atualizado com a CAIXA" e valores de prêmio.
  • Clicar em uma loteria abre o modal com dezenas e faixas de prêmio.
  • resultados.html mostra as 10 loterias com concurso e data recentes.
  • A página de estatísticas da Mega-Sena mostra "X concursos, do 1º ao …" com o número do último concurso divulgado pela CAIXA.
  • O botão do WhatsApp abre uma conversa com o número certo.
  • O link "Abrir no Google Maps" leva à lotérica.
  • O site abre bem no celular (menu ☰ funciona).
  • O menu do WordPress tem o link para /loterias/.

Manutenção

Não há manutenção obrigatória. Resultados, prêmios, próximos concursos e o histórico das estatísticas se atualizam sozinhos. Se quiser mudar telefone, horário ou WhatsApp, edite apenas assets/js/coli-config.js e envie de novo pelo Gerenciador de Arquivos.

Se um dia a CAIXA mudar o endereço da API, a linha a alterar é const CAIXA_API no topo de api/loterias.php.

Perguntas frequentes

Por que o valor do prêmio às vezes demora?

A CAIXA publica o resultado primeiro e a estimativa do próximo prêmio alguns minutos depois. O site reconsulta a cada 5 minutos e quando a aba volta ao foco.

A faixa está amarela: "sem conexão com a CAIXA"

A API da CAIXA oscila, principalmente na hora do sorteio (20h–21h). O site mostra os últimos dados salvos e volta ao normal sozinho. Se a faixa ficar amarela por horas, faça o teste do passo 6.

Posso mudar o nome da pasta depois?

Sim. Renomeie a pasta e ajuste o link no menu do WordPress (e o redirecionamento da Opção B). Tudo dentro do site usa caminhos relativos.

Subi o zip novo, mas o site continua igual (ícone antigo, botão antigo, "Time do Coração" na Mega-Sena)

É cache: o navegador ou a hospedagem guardou o coli-core.js e o coli.css antigos. A partir desta versão isso não acontece mais, porque cada página chama os arquivos com um número de versão (coli-core.js?v=…) que muda a cada pacote, e o .htaccess manda o navegador sempre reconferir as páginas. Para a troca atual, faça uma vez:

  1. Apague a pasta antiga por completo e extraia o zip novo (não só copie por cima). Confira que .htaccess, apple-touch-icon.png e apple-touch-icon-precomposed.png estão na raiz da pasta.
  2. Se o WordPress tiver plugin de cache (LiteSpeed Cache, WP Rocket, W3 Total Cache, WP Super Cache), clique em Limpar todo o cache. Se usar Cloudflare, em Caching → Purge Everything.
  3. No computador, recarregue com Ctrl+Shift+R (Mac: Cmd+Shift+R). No iPhone, Ajustes → Safari → Limpar Histórico e Dados.
  4. Ícone da tela inicial do iPhone: apague o atalho antigo e adicione de novo. O iOS grava o ícone no momento em que o atalho é criado e nunca o atualiza sozinho.

Quero o site em um subdomínio (resultados.coliloterias.com.br)

No painel, crie o subdomínio apontando a raiz de documentos para public_html/loterias. Nenhuma alteração no site é necessária.
